Why choose vixcode?

Designed for power users who want intelligent automation without sacrificing privacy.

🔒

100% Local

No API keys, no cloud servers. Everything runs on your own hardware via Ollama.

🤖

Agentic Loop

It doesn't just chat. The LLM autonomously plans, reads files, writes code, and executes commands.

🛡️

Permission System

You're in control. Read operations auto-approve, while writes & shell commands require your explicit permission.

🌐

Dual Interface

Use the blazing-fast CLI (REPL) in your terminal, or the beautiful dark-mode Web UI in your browser.

⚡

Dynamic Tools

6 built-in tools including file reading, editing, listing directories, and searching code patterns.

📦

Context Compression

Smart memory management automatically compresses older conversation context to save tokens.

Ready to run it locally?

Start your private agent in seconds via Docker or native Python.

Docker 
# Clone the repository
git clone https://github.com/sechan9999/LLMai.git
cd LLMai

# Run via Docker Compose (make sure Ollama is running locally)
docker-compose up -d

# Open your browser to http://localhost:7777
