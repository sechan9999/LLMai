Built for power users who care about privacy

🔒

100% local

Runs against a local Ollama instance. No outbound API calls, no telemetry, no account required.

🤖

Real agentic loop

Up to 20 iterations of plan → tool → observe per turn. The model chains reads, edits, and tests on its own.

🛡️

Explicit-permission writes

Reads and searches auto-run. write_file, edit_file, and run_command require explicit approval.

🔧

Six built-in tools

read_file, write_file, edit_file, list_files, search_code, run_command — all path-sandboxed.

How it works

1

You ask in plain language

Type into the UI: "add pagination to the products endpoint and update the tests."

2

Ollama plans the next step

The agent calls your local model with the conversation and a list of tools.

3

Tools run, sandboxed to your workspace

Read-only tools execute immediately. Mutating tools pause for your approval.

Run it locally in under a minute

Make sure Ollama is running and a model is pulled.

git clone https://github.com/sechan9999/LLMai.git cd LLMai pip install -e . # In another terminal: ollama serve ollama pull qwen2.5-coder # Launch the Web UI: vixcode-server
